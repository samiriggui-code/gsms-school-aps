# Catalogue & sessions (landing)

## Prérequis

1. **Formation** créée dans le CRM avec **offre catalogue active**.
2. **Session** à venir rattachée à cette formation.

## Vérification

- CRM : **Vie scolaire → Formations** et **Sessions**
- Site : les API `catalog/formation` et `catalog/sessions` lisent ces données.

## Checklist hebdomadaire

- [ ] Retirer ou clôturer les sessions passées
- [ ] Vérifier les libellés de dates
- [ ] Tester une préinscription test de bout en bout

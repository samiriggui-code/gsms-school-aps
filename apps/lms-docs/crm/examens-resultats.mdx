# Examens

## Accès

**Gestion académique → Vie scolaire → Examens**

## Public concerné

Uniquement les **inscrits session** ayant un dossier candidature (`FormationSessionParticipant`).

## Saisir un résultat

1. Repérer le candidat dans la liste.
2. Choisir le résultat :
   - **En attente** (PENDING)
   - **Réussi** (PASSED) — obligatoire pour la clôture
   - **Échoué** (FAILED)
   - **Absent** (ABSENT)

La date d'examen est enregistrée automatiquement.

## Après un examen réussi

Passer à [Attestations](/crm/attestations) puis [Clôture](/crm/cloture-archivage).

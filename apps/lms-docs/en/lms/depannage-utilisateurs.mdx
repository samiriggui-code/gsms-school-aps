# User troubleshooting

This guide covers the most frequent user-side incidents.

## 1) Unable to sign in

Checklist:

- Verify email entered
- Verify account status (active/blocked)
- Offer password reset
- If still failing: escalate to technical support

## 2) Access denied to an area

Checklist:

- Verify user role (admin, crm_user, trainer, candidate)
- Verify the user is directed to the correct application
- Verify they have the required permissions

## 3) Course or lesson not visible

Checklist:

- Verify content is published
- Verify the candidate is assigned to the correct pathway
- Verify administrative file status

## 4) Progress blocked

Checklist:

- Ask the user to replay the last lesson
- Verify whether the activity is marked complete
- Log the case and escalate if reproducible

## 5) Escalation process

- Individual incident: handle via standard admin support
- Multi-user incident: immediate escalation
- Critical incident (global block): high priority + internal communication

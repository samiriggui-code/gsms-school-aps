# Catalogue & sessions (landing)

## Prerequisites

1. **Course** created in the CRM with an **active catalogue offer**.
2. Upcoming **session** linked to that course.

## Verification

- CRM: **Student life → Courses** and **Sessions**
- Site: the `catalog/formation` and `catalog/sessions` APIs read this data.

## Weekly checklist

- [ ] Remove or close past sessions
- [ ] Verify date labels
- [ ] Run an end-to-end test pre-registration

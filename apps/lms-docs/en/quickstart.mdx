# Getting started — candidate journey

## 1) Access

- CRM (port 3002)
- Landing (port 3000)
- Docs (port 3004)

## 2) Test scenario (30 min)

<Steps>
  <Step title="Publish course + session">
    CRM → Courses (active catalogue) → Upcoming sessions.
  </Step>
  <Step title="Landing pre-registration">
    Form with email `test+…@domain.com`. See [pre-registration](/en/landing/preinscription).
  </Step>
  <Step title="Validate the file">
    CRM → Application → **Validated** status. Lead becomes **Converted**.
  </Step>
  <Step title="Enroll in session">
    Sessions → enroll the file. See [enroll in session](/en/crm/inscrire-session).
  </Step>
  <Step title="Passed exam + certificate">
    Exams → PASSED then Certifications → certificate.
  </Step>
  <Step title="Close and archive">
    Candidate file → Journey → Close then Archive. See [closure](/en/crm/cloture-archivage).
  </Step>
</Steps>

## 3) Checklist

- [ ] Lead visible in CRM Marketing
- [ ] Application validated with compliant documents
- [ ] Session enrollment confirmed
- [ ] Certificate issued after passed exam

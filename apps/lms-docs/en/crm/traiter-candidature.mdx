# Process an application

## Access

**Academic management → Student life → Applications**

## File statuses

```text
Draft → Submitted → Missing documents → Validation / CNAPS → Validated
```

Terminal statuses: **Rejected**, **Journey completed**, **Archived**.

## Common actions

1. **Check documents** — move to "Missing documents" if follow-up is needed.
2. **Track CNAPS** — dates, reference, favorable / unfavorable opinion.
3. **Validate the file** — status **Validated**:
   - account moves to **student** role;
   - linked lead moves to **Converted**.

## Journey tab (candidate file)

Displays the 8 steps of the [complete journey](/en/lms/parcours-candidat-complet) and closure buttons (after exam + certificate).

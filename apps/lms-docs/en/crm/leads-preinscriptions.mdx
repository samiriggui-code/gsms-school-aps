# Leads & pre-registrations

## Access

**Communication & content → Marketing → Lead forms**

## Processing

1. Filter **New** entries.
2. Open the record — verify course / session / contact details.
3. Contact the candidate and log the response in notes.
4. Update lead status: **Contacted** → **Qualified**.

## Link to the application

Each landing pre-registration creates a **linked application** (`leadId`). Open the file in **Student life → Applications**.

## Automatic conversion

When the application file moves to **Validated**, the lead automatically moves to **Converted** in the database.

## Edge case

Lead without application (legacy data): use **Convert to application** from the lead record.

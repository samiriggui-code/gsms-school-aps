# Certificates

## Access

**Academic management → Student life → Certifications**

## When to issue

After a **passed exam** (PASSED) for a candidate enrolled in the session.

## Procedure

1. Retrieve the **application ID** (candidate file → Journey tab or file URL).
2. Enter the certificate title (e.g. "SSI Certificate — March 2026 session").
3. Save.

## In the database

Creates a **FormationAttestation** row linked to the candidate, course, and optionally the session.

<Warning>
  Without a certificate, the "Close journey" button will be blocked.
</Warning>

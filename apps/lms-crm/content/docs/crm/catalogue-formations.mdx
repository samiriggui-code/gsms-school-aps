# Catalogue formations

## Accès

**Gestion académique → Vie scolaire → Formations**

## Créer / publier

1. Renseigner la fiche formation (intitulé, parcours, durée, objectifs).
2. Activer l'**offre catalogue**.
3. Créer des **sessions** à venir.

## Lien landing

Formations actives + sessions = visibles sur le site public.

Suite : [Catalogue landing](/landing/catalogue-sessions)

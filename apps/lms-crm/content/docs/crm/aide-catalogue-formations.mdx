## Rôle dans le CRM

L'écran **Catalogue formations (aide)** (Support & qualité) liste les **fiches du catalogue actif** — ce n'est pas une FAQ séparée. Pour les procédures détaillées, utilisez ce guide école intégré (`/docs`) ou l'onglet **Documentation** dans le CRM.

## Compléter l'aide

1. Maintenir le catalogue dans **Vie scolaire → Formations**.
2. Traiter les demandes dans **Support → Tickets**.
3. Consulter [Catalogue formations](/crm/catalogue-formations) et [Dépannage utilisateurs](/lms/depannage-utilisateurs).

# Traiter une candidature

## Accès

**Gestion académique → Vie scolaire → Candidature**

## Statuts du dossier

```text
Brouillon → Transmis → Pièces manquantes → Validation / CNAPS → Validé
```

Statuts terminaux : **Refusé**, **Parcours terminé**, **Archivé**.

## Actions courantes

1. **Vérifier les pièces** — passer en « Pièces manquantes » si relance.
2. **Suivre le CNAPS** — dates, référence, avis favorable / défavorable.
3. **Valider le dossier** — statut **Validé** :
   - le compte passe au rôle **élève** ;
   - le lead lié passe à **Converti**.

# Devis & factures

## Modèle unique

Il n’y a pas de table `FinanceFacture` séparée. Un **devis** (`FinanceDevis`) devient une **facture** dans l’UI lorsque son statut passe à **`ACCEPTED`** (acceptation plaquette client ou action CRM).

## Accès

**Administration & facturation → Finance → Devis / Factures**

## Lien avec le parcours candidat

Le devis peut être rattaché à un **lead**, une **candidature** ou une **session**. Ce n'est pas une étape obligatoire du parcours pédagogique.

## Usage

1. Lead landing (`/api/quote-requests`) ou fiche Marketing → créer un devis (brouillon).
2. Envoyer la plaquette / email client.
3. À l’acceptation (`ACCEPTED`), le dossier apparaît dans **Factures** (même enregistrement).
4. Enregistrer les **paiements** — alimentent le **budget** (`actualAmount`).

Option : `CRM_FINANCE_AUTO_DEVIS_FROM_LEAD=1` crée un brouillon automatiquement à chaque demande landing.

Le parcours candidat reste indépendant du paiement.

# Devis & factures

## Accès

**Administration & facturation → Finance → Devis / Factures**

## Lien avec le parcours candidat

Le devis peut être rattaché à un **lead**, une **candidature** ou une **session**. Ce n'est pas une étape obligatoire du parcours pédagogique.

## Usage

1. Créer un devis depuis la fiche lead ou candidat.
2. Envoyer la plaquette client.
3. À l'acceptation, générer la facture.

Le parcours candidat (validation → session → examen → archivage) reste indépendant du paiement.

# Planning

## Accès

**Gestion académique → Vie scolaire → Planning**

## Contenu

Liste des **sessions CRM** sur les 6 prochaines semaines avec le nombre d'inscrits.

## Routine quotidienne

1. Consulter les sessions du jour / de la semaine.
2. Vérifier les effectifs inscrits.
3. Croiser avec **Absences formateurs** (RH) si besoin.
4. Ouvrir le détail session pour gérer les inscrits.

Le planning est alimenté par l'API `vie-scolaire/planning` (sessions catalogue, pas l'ancien registre RH).

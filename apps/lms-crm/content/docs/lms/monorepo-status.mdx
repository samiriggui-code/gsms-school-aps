# Monorepo Status

Cette page resume l'etat d'avancement du monorepo LMS et complete `README.md`.

## Scope actif

- Architecture single-tenant (une ecole, pas de multi-tenant actif)
- DB unique `lms_app` pour LMS + CRM
- Auth partagee par `packages/auth`
- Prisma partage par `packages/database`
- **Une seule app Next.js** : `apps/lms-crm` (port dev **3001**)

## Fait

- Landing publique integree dans `app/(site)/`
- CRM dans `app/(protected)/`
- Documentation MDX dans `content/docs/` (rendu `/docs`)
- Schema Prisma unique centralise dans `packages/database/prisma/schema.prisma`
- Seed unique centralise dans `packages/database/prisma/seed.js`
- Signup desactive dans le backoffice CRM (acquisition via landing)
- Pages auth `2fa` et `lockscreen` dans l'app unique

## En cours / priorites

- Espace candidat `(portal)/` et LMS apprenant
- Redirection par role apres login
- Renforcer securite signin/reset (rate limit + logs audit)

## Stack et briques a activer progressivement

- LMS core : cours, modules, lecons, progression, examens
- Paiement: Stripe (phase monetisation, non bloquant pour le core)
- Realtime: Pusher (notifications/evenements live, si utile metier)
- Workers: `packages/workers` pour jobs async et agrégations Redis

# Administrative file management

This guide defines administrative tracking to prevent lost information.

## Standard file lifecycle

1. Request received
2. Document verification
3. Administrative validation
4. Training access activation
5. Follow-up during training

## Best practices

- Always update file status after each action
- Log important exchanges (call, email, follow-up)
- Assign a file owner

## Weekly checkpoints

- Files awaiting documents
- Files awaiting validation
- Validated files without activation
- At-risk dropout files

## Internal escalation

- Administrative block > 48h: escalate to the administrative manager
- Training block: escalate to the training manager
- Sensitive case: notify school leadership

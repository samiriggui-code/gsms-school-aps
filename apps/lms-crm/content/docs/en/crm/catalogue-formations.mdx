# Course catalogue

## CRM access

**Academic management → Student life → Courses**

## Publish on the public site

The landing page only shows **active** offers from your CRM catalogue.

### Recommended workflow

<Steps>
  <Step title="Put the landing in maintenance">
    Use **Put landing in maintenance** in the catalogue toolbar (or CMS → Landing pages).
    Visitors see a maintenance page while you edit.
  </Step>
  <Step title="Edit the catalogue">
    Add, edit or archive offers. Only **Active** offers will be visible after republishing.
  </Step>
  <Step title="Republish">
    Use **Republish catalogue on landing**. The site goes live with the updated catalogue.
  </Step>
</Steps>

## Create an offer

1. **Add to catalogue** — pick a course from the library or enrich the record.
2. Set price, funding, prerequisites and programme.
3. Set catalogue status to **Active**.

## Sessions

Create upcoming **sessions** for each published course.

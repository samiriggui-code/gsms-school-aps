# Course catalogue

## Access

**Academic management → Student life → Courses**

## Create / publish

1. Complete the course record (title, pathway, duration, objectives).
2. Enable the **catalogue offer**.
3. Create upcoming **sessions**.

## Landing link

Active courses + sessions = visible on the public site.

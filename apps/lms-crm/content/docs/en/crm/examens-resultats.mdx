# Exams

## Access

**Academic management → Student life → Exams**

## Scope

Only **session enrollees** with an application file (`FormationSessionParticipant`).

## Enter a result

1. Locate the candidate in the list.
2. Choose the result:
   - **Pending** (PENDING)
   - **Passed** (PASSED) — required for closure
   - **Failed** (FAILED)
   - **Absent** (ABSENT)

The exam date is recorded automatically.

## After a passed exam

Proceed to [Certificates](/en/crm/attestations) then [Closure](/en/crm/cloture-archivage).

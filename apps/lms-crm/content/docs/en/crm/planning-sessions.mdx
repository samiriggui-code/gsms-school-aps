# Planning

## Access

**Academic management → Student life → Planning**

## Content

List of **CRM sessions** over the next 6 weeks with enrolled headcount.

## Daily routine

1. Review today's / this week's sessions.
2. Check enrolled numbers.
3. Cross-check with **Trainer absences** (HR) if needed.
4. Open session detail to manage enrollees.

Planning is fed by the `vie-scolaire/planning` API (catalogue sessions, not the legacy HR register).

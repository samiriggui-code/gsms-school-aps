# Module: gouvernance-donnees

Sous-domaines API cibles:

- `storage-conformite` — inventaire FileAsset
- `storage/socle` — état arborescence + initialisation (GET/POST)
- `compliance/templates` — catalogue modèles de dossier (GET/POST ensure)
- `compliance/dossiers` — instances par candidature / user (GET)
- `compliance/requests` — demande de pièce + e-mail (POST)
- `compliance/items/[id]/validate` — valider pièce (POST)
- `compliance/dossiers/[id]` — détail + POST evaluate
- `demandes-documents`
- `corbeille-archivage`
- `audit-documentaire`
